# MusicMemo 画面仕様（A案-2）

2026-10-13 · osa

コードとメロディを譜面入力でスケッチし、Logicへ書き出すための個人用アプリ。本格的なアレンジ・仕上げはLogic／Sunoに任せ、このアプリはアイデアを素早く残すことに絞る。

## 参照ファイル

| ファイル | 内容 |
| --- | --- |
| `screens/01_main_100.png` | 基準画面（倍率100%）。これを正とする |
| `screens/02_zoom_200.png` | ズームイン（200%）時のイメージ |
| `screens/03_zoom_50.png` | ズームアウト（50%）時のイメージ |
| `reference/*.html` | 上記3画面の静的HTML。寸法・色・座標の正確な値はここから読む（ブラウザで開ける） |

画像とHTMLはデザインモック。実装はネイティブ（SwiftUI想定）で、HTMLの構造をそのまま移す必要はない。

## 概要

- **対象**：iPad（主）、Mac（同一コードベース。SwiftUI＋Mac Catalyst または マルチプラットフォーム想定。**未確定**）
- **基準画面**：iPad 11インチ横向き 1194×834pt。デザインはこのサイズで作成
- **今回の範囲外**：コード入力ビュー（後でダイアログかサイドバーとして実装）

## 画面構成

画面は上から「トップバー／セクション行／譜面ビュー／全体ビュー／入力パレット」の5段で、譜面ビューだけが高さ可変。

| 領域 | 寸法（pt） | 内容 |
| --- | --- | --- |
| トップバー | 高さ64 | 戻る、曲名とキー・拍子・テンポ・小節数・トラック数、再生／ループ／メトロノーム、元に戻す／やり直す、Logicへ書き出し |
| セクション行 | 高さ約24 | セクション切替（Aメロ／サビ／＋セクション）、右端に表示範囲と入力位置 |
| 譜面ビュー | 残りの高さ（可変） | 再生範囲バー18＋ルーラ28＋トラック行。左にトラック情報列（幅196）、右に縦スクロール列（幅16） |
| 全体ビュー | 高さ約70 | セクション名＋小節カード。左右は譜面部分の幅に揃える |
| 入力パレット | 高さ206 | 音価（幅228）／鍵盤（可変）／入力方法（幅168） |

画面の外周余白は左右18pt、譜面ビューと全体ビューの間は10pt。

## 譜面ビュー

全トラックを縦に並べ、各トラックを改行しない横一行の五線譜で表示する。上から「再生範囲バー → ルーラ → トラック行×N」の順。

### トラック行

- 1トラック＝1行。小節は横に続き、横スクロールで移動（改行しない）
- 100%時の表示量：4小節 × 4トラック（1行の高さ 約90pt、五線の間隔 8pt、1小節の幅 222pt）
- 音部記号はトラックごと（ベースはヘ音記号）。拍子記号は曲頭のみ
- コードトラックは五線の上にコードネームを表示（オレンジ）
- 選択中トラックはヘッダを薄い青で強調。入力中の小節は薄い青で塗る
- 未確定の音符（入力予定位置のプレビュー）は半透明の青で表示

### トラック情報（左列、幅196pt、幅は倍率に依らず固定）

- 楽器名＋役割（例：Piano／メロディ）
- 音量スライダ（0–100）
- パンスライダ（−64〜+63、値を「C／L16／R20」形式で右に表示）
- 左端に4ptのトラック色バー

### ルーラ（高さ28pt）

- 目盛りは4段階：小節（番号付き・最長）＞拍＞8分＞16分（最短・最も薄い）
- 目盛りの位置は音符の拍位置と揃える
- 左列に「小節 · 拍」と現在位置（例：7 . 1 . 1＝小節 . 拍 . 16分）を赤字で表示

### 再生範囲バー（ルーラの上、高さ18pt）

- Premiereのワークエリアバー相当。始点〜終点を青い帯で示す
- 両端のつまみをドラッグして範囲を変更（スナップ単位は小節または拍）
- 左列に「再生範囲 6.1 → 8.1」と表示
- 範囲の始点・終点から全トラックを貫く青い点線を薄く引く
- トップバーのループボタンと連動（オン時は範囲をループ再生）

### 編集位置ライン

- 赤の縦線（2pt）をルーラから全トラックの最下部まで引く。ルーラ上に赤い三角マーカー
- 音符入力はこの位置に行い、入力後は音価分だけ自動で進む

### 縦スクロールバー

- 譜面ビューの右端（幅16pt列、バー自体は8pt）
- つまみの長さ＝表示トラック数／全トラック数

## 全体ビュー（横スクロールバー）

曲全体の小節をコード付きのカードで並べ、譜面ビューの横スクロールバーとして働かせる。

- **配置**：譜面ビューの直下。左端はトラック情報列の右端（譜面の開始位置）、右端は縦スクロールバーの手前に揃える
- **セクション名**：カード列の上に「Aメロ／サビ」などを左罫線付きで表示
- **小節カード**（1小節＝1枚、高さ46pt）：コード名＋小さな五線。空の小節は点線・グレー。入力中の小節は薄い青＋青い点
- **表示範囲の枠**：譜面ビューに今見えている小節を青い枠（2pt）で囲む。幅は倍率に応じて変わる
- **操作**：枠をドラッグして横スクロール。カードをタップするとその小節へジャンプ。枠の両端のつまみで幅を変えるとズーム（未確定）
- 曲が長くてカードが収まらない場合の扱いは未定（未決事項参照）

## ズーム

譜面ビューはSafariのように2本指ピンチで自由に拡大縮小できる。譜面部分だけが縦横同比率で変わり、トラック情報列の幅は固定。

- **操作**：ピンチアウトで拡大、ピンチインで縮小。Macはトラックパッドのピンチ／⌘＋ホイールを想定
- **倍率HUD**：ズーム中、譜面ビュー上部中央に暗いピルを表示。「−／倍率／＋／100%に戻す」
- **連動するもの**：赤い編集位置線、ルーラ、再生範囲、縦スクロールバーのつまみ、全体ビューの表示枠

| 倍率 | 表示量（例） | ルーラ | トラック情報 |
| --- | --- | --- | --- |
| 200% | 2小節 × 2トラック | 16分まで＋拍番号。譜面に8分ごとの薄い縦線 | 楽器名・音量・パン＋ミュート／ソロ／音色選択 |
| 100% | 4小節 × 4トラック | 16分まで | 楽器名・音量・パン |
| 50% | 8小節 × 6トラック | 拍まで（8分・16分は間引く） | 楽器名＋音量とパン値の1行表示 |

倍率の上限・下限と、表示を切り替えるしきい値は実装時に調整する。

## 入力パレット

画面下部（高さ206pt）に常設し、左から「音価／音高／入力方法」の3ブロック。入力は「音価を選ぶ → 鍵盤を叩く → 編集位置が音価分進む」の繰り返し。

### 音価（幅228pt、3×3グリッド、ボタン高さ44pt）

- 1行目：全音符・2分・4分
- 2行目：8分・16分・付点
- 3行目（薄い地色）：4分休符・タイ・3連符
- 表示は文字ではなく音符の絵。フォントに依存しないようベクターで描く
- 付点は薄い音符＋濃い点、タイは弧で繋いだ2音、3連符は連桁＋「3」
- 選択中は青地に白い音符。付点・タイ・3連は音価に重ねる修飾として扱う

### 音高（鍵盤）

- 2オクターブ（白鍵14・黒鍵10）。初期範囲 C4–B5、「‹ ›」で1オクターブずつ移動
- Cの白鍵に音名（C4、C5）を表示
- 編集位置のコードの構成音（例：Dm7 なら D F A C）にオレンジの点。見出しに「Dm7 のコードトーン」と表示
- 押した鍵は青枠＋薄い青でハイライト

### 入力方法（幅168pt）

- 「鍵盤／譜面を直接タップ／MIDIキーボード」の切替
- 下に「入力後は自動で次の拍へ進む」と表示

## データモデルと書き出し

画面に出ている情報から起こした最小構成の叩き台。時間の位置は16分音符より細かい単位（tick）で持ち、3連符も表せるようにする。

| 要素 | 主な項目 |
| --- | --- |
| 曲（Sketch） | タイトル、キー（例：C major）、拍子（4/4）、テンポ（♩=96）、再生範囲（始点・終点）、ループのオン／オフ |
| セクション | 名前（Aメロ、サビ…）、開始小節、小節数 |
| コード進行 | 小節・拍位置ごとのコード名（ルート、質、分数コードのベース音）。鍵盤の構成音表示と全体ビューに使う |
| トラック | 楽器名、役割、音部記号、色、音量（0–100）、パン（−64〜+63）、ミュート、ソロ、音色（GMプログラム番号など） |
| 音符 | 開始位置（tick）、長さ（tick）、音高（MIDIノート番号）、タイ、休符かどうか |
| 画面状態 | 編集位置、選択中のトラック、倍率、スクロール位置、選択中の音価 |

- **書き出し**：トップバーの「Logicへ書き出し」から Standard MIDI File（トラックごと、テンポ・拍子付き）と MusicXML（コード記号付き）を出力
- コード記号はMIDIに載らないため、MusicXMLを主、MIDIを従とするのが自然（未確定）

## ビジュアル仕様

白い紙面に墨色の譜面、操作はコバルトブルー1色、コードはオレンジ、編集位置だけ赤。

| 用途 | 色 |
| --- | --- |
| 背景／紙面・パネル | #EEF0F2 ／ #FFFFFF |
| 文字・音符（墨） | #1B1D21 |
| 補助の文字 | #5A606B、より薄いもの #8A909A |
| 罫線 | #D9DCE1、#C9CDD3 |
| アクセント（選択・再生・表示範囲） | #2F5BEA、薄い青 #EAF0FE ／ #DCE5FD |
| コード名・コードトーン | #C2541F |
| 編集位置ライン | #D92D20 |
| トラック色 | 青 #2F5BEA、オレンジ #C2541F、緑 #3D7A5C、紫 #7A5AB8、黄土 #B08A1E、グレー #5A606B |

- **フォント**：IBM Plex Sans JP（なければヒラギノ角ゴ）。音符や記号は自前で描くか、SMuFL対応の楽譜フォント（Bravuraなど）を同梱する。端末によって記号の見た目が変わるため
- **タッチターゲット**：主要ボタンは44pt以上
- **角丸**：カード・パネル14pt、ボタン8〜10pt
