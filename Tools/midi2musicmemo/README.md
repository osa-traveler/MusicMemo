# midi2musicmemo

MIDI ファイル（.mid）を MusicMemo の曲（.musicmemo）に変換するコマンド（Mac）。昔作った MIDI をまとめて変換するときに使う。
1曲ずつなら、アプリ（Mac）のファイルメニュー「MIDI を読み込む…」でも同じ変換ができる。変換の処理は `Packages/MusicMemoCore` の `MIDIImporter`（と `SMFReader`）で、アプリと共通。ここにはコマンドの入口だけがある。

## 使い方

```sh
cd Tools/midi2musicmemo
swift run -c release midi2musicmemo ~/Music/song.mid            # song.mid と同じフォルダに song.musicmemo
swift run -c release midi2musicmemo -d ~/Desktop/曲 *.mid       # まとめて変換して、出力先のフォルダに置く
```

| オプション | 内容 |
| --- | --- |
| `-o パス` | 出力ファイル（入力が1つのとき） |
| `-d フォルダ` | 出力先のフォルダ |
| `--grid 16t` / `--grid 16` | そろえる格子。`16t` は16分と8分3連（初期値）、`16` は16分だけ（3連符に化けるときに） |
| `--key "D major"` | 調を指定する（MIDI の調号より優先。調号の無い MIDI は C major になる） |
| `-f` | 同じ名前の出力ファイルがあれば上書きする（初期値は上書きしない） |

変換のたびに、曲の設定・トラックの対応と、読み込めなかったもの（⚠︎）を表示する。できたファイルを iCloud Drive などに置いてアプリで開く。

## 変換のきまり

| 項目 | 内容 |
| --- | --- |
| 曲名 | 元のファイル名 |
| キー・拍子・テンポ | MIDI の最初の値。途中で変わるときは最初の値のまま（⚠︎ で知らせる）。拍子は 2/4・3/4・4/4 だけなので、6/8 → 3/4、12/8 → 4/4 のように小節の長さが同じものに置き換える。ほかは 4/4。テンポは 0.1 単位、40〜240 に収める |
| セクション | MIDI のマーカーの位置（一番近い小節線）と名前。マーカーが無ければ曲全体を「Aメロ」1つ |
| トラック | MIDI のトラックごと（1つのトラックに複数のチャンネルがあればチャンネルごと）。10ch（ドラム）は除く。15本まで。名前は MIDI のトラック名（無ければ、またはフォーマット0なら GM の音色名）。音色・音量（CC7）・パン（CC10）は最初の値 |
| 役割 | ベース：GM のベース、または音域が低くほぼ単音。コード：3音以上の和音で始まる所が3割以上（シンセパッドの音色ならパッド）。メロディ：ほぼ単音で音符が十分ある中で一番音域の高い1本。ほかは「その他」。色は役割に合わせる |
| 音部記号 | 音高の中央値が G3 より下ならヘ音記号 |
| クオンタイズ | 拍ごとに、音の頭が16分と8分3連のどちらの格子に近いかを比べて選び（3連のずれが16分の6割より小さければ3連）、頭と終わりをそろえる。短すぎる音は格子1つ分にする |
| 整理 | 同じ位置で始まる和音の終わりのばらつき（16分以内）は一番長い音にそろえる。同じ高さの音の重なりは前の音を切る。次の音へ16分以内だけ食い込む音（レガート）はその頭で切る |
| 記譜 | 小節線・3連の拍の境目・1つの記号で書けない長さは分けてタイでつなぐ。2つの声部に収まらない小節は、重なる音を境目で分けてタイでつなぎ、和音にする |
| 読まないもの | ベロシティ、ピッチベンド、ペダル、歌詞、コード記号、途中の音色の変更 |

## テスト

変換のテストは MusicMemoCore にある（`Tests/MusicMemoCoreTests/MIDIImporterTests.swift`）。

```sh
cd Packages/MusicMemoCore && swift test
```

MusicMemo で書き出した MIDI を読み戻して元の曲と一致すること（往復）、手弾きのずれ・3連符・小節線をまたぐ音・声部の整理・フォーマット0・ランニングステータス・Shift_JIS の名前・RMID を確かめている。
